# SIMILIS baseline

Baseline for formalized archaeological artifact description from images.

The solution predicts four visual fields and builds `auto_description` with a fixed template:

- `name_norm`: artifact type
- `material_norm`: material
- `part_norm`: artifact part or zone
- `fragm_norm`: integrity

The main output for evaluation is a CSV with at least:

- `image_file`: relative path to input image
- `auto_description`: generated formalized description

Additional `pred_*` and `confidence_*` columns are written for transparency.

## Data preparation

The data preparation notebook builds the working corpus:

```text
notebooks/SIMILIS_data_prep_v2.ipynb
```

It links CSV rows to images, removes unusable silhouette masks, normalizes labels, builds `group_key`, and creates a group-aware split.

The resulting training files are expected in:

```text
data/interim/df_prepared.csv
data/interim/label_encoders.json
data/interim/target_fields.json
```

In the original Colab runs these files were saved under:

```text
/content/drive/MyDrive/cu_data/similis_artifacts/interim/
```

## Training

The main training notebook is:

```text
notebooks/SIMILIS_Training.ipynb
```

Equivalent script entrypoint:

```bash
python src/train.py \
  --data-csv data/interim/df_prepared.csv \
  --label-encoders data/interim/label_encoders.json \
  --output-dir artifacts/checkpoints \
  --epochs 30 \
  --batch-size 32
```

The script saves:

```text
artifacts/checkpoints/best.pt
artifacts/checkpoints/last.pt
```


## Inference

Run inference on a directory with images:

```bash
python src/predict.py \
  --image-dir path/to/images \
  --checkpoint artifacts/checkpoints/best.pt \
  --output-csv artifacts/preds/predictions.csv
```

Example output columns:

```text
image_file, auto_description,
pred_name, confidence_name,
pred_fragm, confidence_fragm,
pred_material, confidence_material,
pred_part, confidence_part
```

`image_file` is saved relative to `--image-dir`.

## Baseline configuration

The baseline configuration is fixed in:

```text
configs/baseline.json
```

Main settings:

- backbone: `convnext_tiny.fb_in22k_ft_in1k`
- image size: 384
- preprocessing: resize longest side + pad
- augmentations: horizontal flip, small rotation, mild ColorJitter
- optimizer: AdamW
- scheduler: CosineAnnealingLR
- selection metric: mean macro-F1 on validation

## Metrics and validation

The project uses a group-aware split by `group_key`; train, val and test groups do not overlap.

Validation metrics are reported separately for every field:

- accuracy
- macro-F1

The aggregate model selection metric is mean macro-F1 across the four fields.

The best notebook run reached about:

```text
best val mean macro-F1: 0.4937
```

Final `test_open` metrics should be generated by the notebook or by evaluating `best.pt` once on the held-out test split.
